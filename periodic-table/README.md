# Interactive Periodic Table

A reference-inspired, self-contained interactive periodic table built from the supplied video design.

## Included
- Responsive dark UI
- Classic 18-column periodic layout
- 3D sphere mode
- 3D helix mode
- Grid mode
- Search/filter by symbol or atomic number
- Clickable element detail cards
- No external runtime dependencies

## GitHub Pages
The deployment workflow is included at `.github/workflows/periodic-table-pages.yml`. GitHub Pages must use **GitHub Actions** as its source for the workflow to publish the site.
